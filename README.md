# Colegio Integral San Miguel

Sitio web institucional del Colegio Integral San Miguel, desarrollado con HTML, CSS y JavaScript como proyecto académico y de presentación institucional.

## Descripción

Este proyecto consiste en una página web informativa y visual para la institución, donde se muestran secciones como:

- Inicio
- Nosotros
- Programas académicos
- Servicios
- Galería
- Noticias
- Contacto
- Inicio de sesión

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Estructura del proyecto

- `index.html`: página principal del sitio
- `login.html`: formulario de inicio de sesión
- `css/`: archivos de estilos por secciones
- `js/`: scripts interactivos
- `img/`: imágenes institucionales

## Cómo visualizar el proyecto

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Si deseas, también puedes abrirlo desde un servidor local para una mejor experiencia.

## Funcionalidades

- Diseño responsivo
- Navegación por secciones
- Formulario de contacto
- Inicio de sesión con ventana emergente
- Estilo institucional con identidad visual del colegio

## Autor

Proyecto desarrollado para la institución educativa Colegio Integral San Miguel.

## Notas

Este proyecto puede ampliarse con nuevas secciones, integración con bases de datos o una plataforma educativa más completa.
